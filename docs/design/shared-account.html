1. Goal and non-goals

Goal. Simulate a book the way a broker account and Nautilus do: every pair in the book trades from one shared account with one margin pool. A trade is accepted only if the account has the free margin for it; when the account's equity falls to its total maintenance margin, every position is closed.

Why it is a real change. Today each pair is an independent run and the book is added up afterwards. With a shared account the pairs affect each other (one pair's losses can block another pair's entry), so all pairs of a book must step through time together in one engine.

Non-goals. Costs (spread, commission, swap) stay out. Equities keep today's behaviour. Sizing stays a fixed notional per pair. No change to strategy logic.

5. Use cases

UC1 Run a margin book

Trigger: a simulation with a margin setting over N pairs. Main: the engine builds one account with N × $10,000, one strategy per pair, and steps every pair's minute bars in time order. Postcondition: one account table plus one result per pair.

Alternates: A1 two pairs decide at the same minute: ticker order (D22). A2 a pair has no bar at a minute (FX holiday for one, not another): that pair is simply not advanced; its last close stays its mark.

UC2 Enter under a shared account

Main: initial margin fits in free margin, order accepted. Alternates: B1 another pair's open positions and working stop entries have used the free margin: rejected. B2 a working stop entry locks its initial margin until it fills or is cancelled. B3 close or reduce: always accepted.

UC3 Losses across pairs

Main: account equity falls but stays above total maintenance. Alternates: C1 a pair crosses its wake-up level: exact check; no liquidation; levels recomputed. C2 exact check finds equity ≤ maintenance: every order cancelled, every position closed at its latest close. C3 a gap makes equity end below maintenance or below 0: recorded as is. C4 after liquidation a strategy re-enters: rejected while free margin is short.

7. Pseudocode

class MarginSpec(BaseModel, frozen):
    leverage: float = 30.0                       # D2
    maintenance: float = 0.5                     # D3
    def initial(self, notional_usd) -> float:     return notional_usd / self.leverage
    def maint(self, notional_usd) -> float:       return self.initial(notional_usd) * self.maintenance

class ExecutionSpec:  ... margin: MarginSpec | None = None     # None: today's single-pair path (D25)

class SharedAccount:                             # new, one per book (D17)
    balance: float                               # realized only (S2, D19)
    sleeves: list[Sleeve]                        # ticker order (D22)
    margin: MarginSpec

    def locked(self) -> float:                   # S3, D19
        return (sum(margin.initial(order_notional(o)) for s in sleeves for o in s.working if o.prices_an_entry)
              + sum(margin.maint(s.entry_notional()) for s in sleeves if s.position))
    def free(self) -> float:        return max(0.0, balance - locked())
    def equity(self) -> float:      return balance + sum(s.unrealized(s.mark) for s in sleeves)
    def maintenance(self) -> float: return sum(margin.maint(s.entry_notional()) for s in sleeves if s.position)
    def settle(self, realized):     balance += realized       # called by each sleeve's portfolio

class Sleeve:                                    # today's per-pair machinery, account injected
    ticker; context; matcher; strategy; stream; j (index); mark (latest close)
    capital_share                                # D20, D23
    def equity_curve_point(self) -> float:       return capital_share + realized_own + unrealized(mark)

class BookEngine:                                # new (S1)
    def run(self):
        while any sleeve has bars left:
            t = min(next_event(s) for s in sleeves)          # fast-forward per sleeve + wake levels (D18)
            for s in sleeves where s.next_time == t:          # ticker order (D22)
                s.step(t)                                     # same per-bar code as today: fills, protect, on_bar, marks
            if account has positions and (any wake level crossed or a fill happened):
                if account.equity() <= account.maintenance():   # S5
                    liquidate(t)
                set_wake_levels()

    def set_wake_levels(self):                   # D18: exact safety bound
        open = [s for s in sleeves if s.position]
        cushion = account.equity() - account.maintenance()
        for s in open:
            s.wake = price where s.unrealized(price) = s.unrealized(s.mark) - cushion / len(open)
                     # solved with the same closed forms as margin.html (identity / reciprocal)
        # if no sleeve crosses its wake price, total loss < cushion, so no liquidation is possible

    def liquidate(self, t):                      # D6, D7
        for s in sleeves: s.context.cancel_all()
        for s in sleeves if s.position: s.close_at(s.mark, tag="liquidation", origin=LIQUIDATION)
        account.liquidated_at = t

# pre-trade (S4, D9, D10, D19), in Sleeve.context.submit
if margin and opens_or_adds(order):
    if margin.initial(opening_notional(order)) > account.free_after_releasing(order):
        order.status, order.reason = REJECTED, "insufficient margin"; s.rejections += 1
